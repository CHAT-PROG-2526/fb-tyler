# Flappy-Bird
Flappy Bird (Class Project)

This workspace contains a browser-based, mobile-responsive Flappy Bird clone built with plain HTML, CSS, and JavaScript.

## Run locally
1. Open `index.html` in a browser.
2. Use tap/click or press `Space` / `Arrow Up` to flap.
3. Toggle sound with the on-screen mute button.

## Files
- `index.html` — game shell and UI
- `styles.css` — responsive pixel-art style and overlay layout
- `script.js` — game loop, physics, controls, audio, and localStorage persistence
- `PROJECT_PLAN.md` — feature backlog and branch/task plan
